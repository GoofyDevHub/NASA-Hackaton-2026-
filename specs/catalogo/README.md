# Catalogo delle risorse NASA

[Quattordici immagini NASA per la demo](campione/README.md) · [Valutazione e confronto per ORBIT](valutazione.md) · [Inventario delle risorse](inventario.csv) · [Indice dei file e delle sequenze](media.csv).

Le righe dell’inventario rappresentano schede, gallerie e collegamenti a servizi. Per i servizi il campo URL asset indica la destinazione del pannello. Il registro dei media distingue gli URL dei file dagli indici di fotogrammi. Per preparare il catalogo offline completare date di osservazione, geografia, condizioni d’uso, maschere, dominio e unità secondo la [specifica](../docs/catalogo.md).
