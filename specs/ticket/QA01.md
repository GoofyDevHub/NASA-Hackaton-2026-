# QA01 · Walk through the site with assistive technology

**Area** Validation

**Depends on** [WEB02](WEB02.md), [WEB04](WEB04.md), [AI03](AI03.md)

Run the judging journey from a fresh browser profile with keyboard and screen reader. Test available braille equipment through its existing software.

## Acceptance

- [ ] With the screen covered, start the playlist, identify the scene, request description, go back and stop. Inspect focus and announcements during navigation.
- [ ] Record browser, OS, assistive tools, braille device availability, results and unresolved issues. Distinguish a team check from a participant session.

## Verify

Repeat with a refused microphone and with enlarged text. Capture actual pass/fail outcomes and retest any blocking fixes.
