# Draft development tickets

These 19 tickets are a working breakdown for a two-person team. Both teammates still need to review the open design choices, feasibility and task ownership. Update a ticket when its input, output or acceptance criteria change. The proposed order is PC listening, controller integration, then comparison. The judging target includes all three products.

Start with DA01 and SW01 for one Pacific pair. Progress through SW02, SO01 and SO02 before expanding the playlist. HW01 and HW02 can progress alongside the player. Final film capture depends on a tested player and controller model.
