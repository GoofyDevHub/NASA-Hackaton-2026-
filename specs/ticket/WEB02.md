# WEB02 · Explore through the globe or the text list

**Area** Player

**Depends on** [WEB01](WEB01.md), [CAT02](CAT02.md)

Connect the globe and equivalent accessible list to the same scene selection. Apply the approved globe, palette and thin orange orbit.

## Acceptance

- [ ] Both entry points open the same labelled panel, and dismissal restores focus. A user can reach all nine views through the list.
- [ ] Display the correct crop and available controls. The thin orange line follows playback and settles at rest. Reduced motion keeps a static view.

## Verify

Select a Congo scene on the globe, then select it again using only the keyboard. Repeat with reduced motion and at 200% zoom.
