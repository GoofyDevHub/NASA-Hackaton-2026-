# AI02 · Control playback with Obit commands

**Area** Obit

**Depends on** [AI01](AI01.md), [WEB04](WEB04.md)

Resolve supported commands to the same selection and transport actions as the visible controls. Confirm the resulting state.

## Acceptance

- [ ] Typed requests can choose a scene, start the playlist, play, pause, stop, navigate, repeat, adjust volume and request a description.
- [ ] An ambiguous request prompts for clarification. Unsupported commands, late replies and image-only play requests cannot start the wrong track.

## Verify

Run a command sequence and the equivalent keyboard sequence. Compare scene, position, volume, repeat and spoken status, including Stop during a pending reply.
