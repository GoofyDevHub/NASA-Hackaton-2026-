# Working on ORBIT

Read the [scope](product.md), [ticket index](ticket/README.md) and the individual ticket before implementing a change. Work on a focused branch based on develop. Keep project-facing text in English and preserve localizable interface labels, including “Parla con Obit”.

Use the six selected tracks and the nine documented views. Access the [audio checksums](../assets/audio/sha256.json) and [image provenance](../assets/images/sources.json) by scene. When changing a mapping, retain the reference master and submit a new listening example for team review.

Use a single playback state for keyboard, mouse, assistive technology and Obit. Keep optional description, assistant speech and sonification intelligible. Report keyboard, screen-reader, braille, microphone and listening tests separately with the device, version and actual result.

Keep experiment output outside the reference folders. Record working features, illustrated ideas and untested claims accurately in the submission.
